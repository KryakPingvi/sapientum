# Sapientum

Система проведения очных командных турниров по решению задач.

## Структура

- `apps/web` — веб-интерфейс участников оргкомитета и табло результатов.
- `apps/api` — сервер и модули предметной области.
- `packages/contracts` — общие схемы запросов, ответов и событий.
- `packages/game-rules` — правила игр и расчёт рейтинга без зависимости от HTTP и БД.
- `tests/e2e` — сквозные сценарии турнира.
- `docs` — описание правил и архитектурных решений.
- `infra` — конфигурация запуска и развёртывания.
- `sapientum.drawio` — схема процессов проекта.

В серверных модулях `domain` содержит предметную логику, `application` — сценарии и интерфейсы внешних зависимостей, `infrastructure` — их реализации, `http` — обработчики запросов. Предметная логика не зависит от HTTP или конкретной БД. Между модулями используются явно определённые операции, а не доступ к чужим внутренним файлам и таблицам.

## Состояние

Создан каркас npm workspaces и реализован серверный модуль оргкомитета: роли, проверка доступа, журнал изменений, хранилище в PostgreSQL и HTTP-адаптер. Подключение и ограничения описаны в [docs/staff.md](docs/staff.md). Сервер авторизации и веб-интерфейс пока не реализованы.

Требуются Node.js 22.19+ и PostgreSQL. Для тестов база поднимается командой `docker compose -f infra/compose.yaml up -d`. Установка зависимостей: `npm install`. Проверки: `npm run typecheck`, `npm test`. Сборка реализованных пакетов: `npm run build`. `tsconfig.base.json` содержит общие настройки TypeScript.

Пустые каталоги сохраняются в Git через `.gitkeep`. После добавления файлов соответствующий `.gitkeep` можно удалить.

Фотографии бланков и другие runtime-данные хранятся вне исходников. Корневые каталоги `data`, `uploads` и `storage` исключены из Git. Пример переменных окружения находится в `.env.example`.
