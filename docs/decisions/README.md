# Решения

В этой папке записано, что мы решили по каждой задаче и почему. Поведение модулей и HTTP-контракты описаны отдельно, в `docs/<модуль>.md`.

На каждую задачу из issues заведён один файл. Он приходит в том же PR, что и код задачи.

| Файл                       | Issue                 | PR  | Код                          |
| -------------------------- | --------------------- | --- | ---------------------------- |
| [01-staff.md](01-staff.md) | #1 Оргкомитет и права | #9  | `apps/api/src/modules/staff` |

## Как устроена запись

Решения в файле пронумерованы. У каждого одни и те же части:

- **Контекст**: что известно из разбора, доски или кода и какую проблему мы решали.
- **Решение**: что сделали.
- **Почему**: довод за это решение.
- **Отвергли**: другие варианты и их минусы. Пункт есть, если варианты обсуждались.
- **Где**: файлы с кодом.
- **Проверка**: тесты, которые упадут, если решение нарушить. Тесты лежат в `apps/api/tests`, названия приведены дословно.

Пометка **«Решили сами»** стоит там, где источники молчат и решение приняла команда. На доске такие места отмечены так же.
