## Как воспроизвести

Из корня, после `npm ci`, с запущенными Docker-базами и свободными 3000/3001/3002:

```powershell
npm run build
node --test scripts/dev-security.test.mjs
npm run dev:process-check
```

Модульные и SQL-проверки: `npm run test:coverage` с DATABASE_URL тестового PostgreSQL. Все перечисленные проверки включены в CI: c8 охватывает API/контракты, а host helper-тесты и HTTP-процессы запускаются отдельными обязательными шагами. Процент c8 сам по себе не является покрытием scripts.

## Что остаётся ограничением

Стенд слушает loopback, использует демопароли и локальный HTTP. Он не является production-развёртыванием. TLS, рабочие секреты и учётные записи БД с минимальными правами требуют конфигурации реального окружения. Service-key уже реализован для внутреннего API; его нельзя отдавать браузеру. Для production ограничения частоты должны учитывать доверенный reverse proxy и риск распределённого перебора, а не слепо доверять X-Forwarded-For. Два параллельных refresh намеренно закрывают семью; будущий полноценный клиент должен объединять refresh между вкладками. Row-lock и обновление сессии остаются осознанной ценой немедленного отзыва, не скрытым утверждением о неограниченном масштабировании.
